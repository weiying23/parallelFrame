# Vibe Debug

## 目标

用可复现、可缩小、可验证的方式定位问题，并产出修复或临时缓解方案。

## 什么时候调用

- 崩溃、死锁、卡住、内存错误、偶现竞态
- 结果不对但无明确报错
- 性能突然退化

## 调试流程

1. 固化复现：最小输入、固定随机种子、固定线程数/进程数
2. 快速分类：构建/运行参数/资源/并发/数值/IO
3. 缩小范围：二分排查、加断言式检查（不引入额外注释）、最小打印
4. 证据收集：调用栈、错误码、边界值、线程状态
5. 修复与验证：修复后复现用例通过，并补最小回归覆盖

## 产出

- 复现步骤与根因分析
- 修复提交（或可选的规避方案）
